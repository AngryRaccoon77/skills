# Local Codex Plugins

`ru-market-portfolio-analyst` анализирует портфели российских акций и облигаций. Python-скрипт рассчитывает распределение активов и объём покупок с учётом лотов.

## Установка в Codex

```sh
codex plugin marketplace add AngryRaccoon77/skills
codex plugin add ru-market-portfolio-analyst@local-codex-plugins
```

В приложении Codex плагин также доступен в каталоге **Local Codex Plugins**. После установки откройте новый чат.

Если для анализа нужны данные брокера, используйте доступ к T-Invest только на чтение.
